# Dr. Enosh A Paulson | Portfolio

Personal portfolio site: https://drenosh.github.io

I'm a dentist building healthcare AI. The site walks through my background and the projects I've built: dental imaging, hospital admission forecasting, segmentation and AI governance.

## Sections

About, Journey, Practice, Play (interactive demos), Work, Wins, Background, Credentials and Contact.

## How it's built

A single static `index.html` with inline styles and scripts. There is no build step and no dependencies. To preview it, open `index.html` in a browser.

| File | Purpose |
| --- | --- |
| `index.html` | The whole site |
| `og.png` | Social share image |
| `robots.txt`, `sitemap.xml` | Search engine files |

It is hosted on GitHub Pages from the `main` branch.
